Set up Slack

Each Foundry runs its own Slack app. An instance operator creates it once:

  1. In Slack, create a new app from a manifest and choose the Slack workspace it belongs to.
  2. Paste the manifest below. It names this Foundry's Slack return address and Slack events address.
  3. An instance admin enters the app's Client ID, Client Secret and Signing Secret under Instance admin › Integrations.
  4. No restart is needed. A workspace admin can then choose Add to Slack on the workspace integrations page.

An instance operator may instead set SLACK_CLIENT_ID, SLACK_CLIENT_SECRET and SLACK_SIGNING_SECRET in Foundry's environment and restart; the environment takes precedence.
