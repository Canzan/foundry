Set up Slack

Each Foundry runs its own Slack app. An instance operator creates it once:

  1. In Slack, create a new app from a manifest and choose the Slack workspace it belongs to.
  2. Paste the manifest below. It names this Foundry's Slack return address and Slack events address.
  3. From the app's Basic Information, set SLACK_CLIENT_ID, SLACK_CLIENT_SECRET and SLACK_SIGNING_SECRET on this Foundry, together with FOUNDRY_SECRETS_KEY.
  4. Restart Foundry. A workspace admin can then choose Add to Slack on the workspace integrations page.
